# 汽水音乐 · 自动领「免N天」免费畅听（安卓 / AutoJs6）

用 [AutoJs6](https://github.com/SuperMonster003/AutoJs6) 在安卓手机里自动做汽水音乐的免费畅听任务：
**发现页右上角「免N天」→ 看一条激励视频 → 天数 +1**。
纯手机内运行，不需要电脑，不需要数据线。

> 这是 [qishui-music-welfare-auto](https://github.com/jianqiang1235/qishui-music-welfare-auto)（iOS/AScript 版）的安卓版本。
> 本版**已按荣耀畅玩40（WDY-AN00 / Android 13 / 720×1612 / AutoJs6 6.8.0）真机实测重写并跑通**，
> 下面所有文案、坐标、Activity 名都来自真机 dump 与实跑日志。

---

## 一句话说清路径

```
发现页（底部 tab「发现」）
  └ 右上角「免18天」             ← 控件树里没有节点，Flutter 自绘，只能 OCR 或按坐标
      └ 点击 → 直接进激励视频广告  ExcitingVideoActivity
          └ 倒计时归零，右上角变「领取成功，关闭，按钮」
              └ 点右上角 → 自动弹「再看N个视频提前得 第M日免费听」浮层
                  └ 点「坚持退出」(360,1006) → 回 App
                      └ App 弹面板「第N天畅听 已领取」 → 点 × 关掉
                          └ 右上角变成「免19天」（+1 天）
```

## 真机实测硬事实

| # | 事实 | 影响 |
|---|---|---|
| 1 | **VIP 期间福利中心整体消失**：底部 tab 变「会员」、播放页无金币入口、会员页只有套餐 | 「福利中心→看广告赚金币」这条老路在会员期**完全不可用** |
| 2 | 但 **「免N天」入口在 VIP 期间照常可用** | 这才是当前唯一可靠的主路径 |
| 3 | 「免N天」是 Flutter 自绘，**控件树里没有 text/desc**（只有一个空节点 `[579,63][634,121]`） | 只能 OCR 认，或按比例坐标 `(0.893, 0.057)` = 643,92 |
| 4 | 点入口**直接**进 `com.ss.android.excitingvideo.ExcitingVideoActivity`，绕过福利中心 | 少了一大堆坐标点击 |
| 5 | 倒计时在 **content-desc**：`19秒后可领取奖励，关闭，按钮`，text 为空 | 先 desc 再 text 再 OCR |
| 6 | 播完**自动弹**「再看N个视频提前得 第M日免费听」浮层（按钮「领取奖励」「坚持退出」） | 不处理就永远退不出广告 |
| 7 | 该浮层**没有任何控件文字**（Flutter 自绘）；**返回键无效**；点「领取奖励」是连播下一条 | 唯一出路是点「坚持退出」= `(0.500, 0.624)` = 360,1006 |
| 8 | 回 App 弹面板：「再看N个提前享第M天畅听 / 恭喜获得第N天免费时长畅听 / 第N天畅听 **已领取**」，× 在 `(0.903, 0.623)` = 650,1004 | 面板文字在 desc 里可读，是判定进度的硬凭据 |
| 9 | 天数越往后**每天要看的条数越多**：第22天 1 条就 +1，第23天起要连看好几条才 +1 | 不能用「看完一条就成功」判，必须看已领取天数是否真的变大 |
| 10 | 广告会**随机变成直播间形式**（`LunaDefaultLivePlayerActivity` / `android.app.Dialog`，界面有「本场点赞 / 更多直播」） | 识别到就退出重试，不跟带货直播间耗 |
| 11 | 荣耀系统管家（`com.hihonor.systemmanager`）会抢前台弹开屏广告，导致 `launchPackage` 失败 | 启动失败后改从桌面点图标；必要时先 force-stop 管家 |
| 12 | AutoJs6 6.8 的 OCR 是**插件**，没装插件时 `ocr.detect` 直接抛异常 | 脚本会探测一次并自动降级为「控件 + 坐标」模式，不再刷错误日志 |
| 13 | 每次无障碍查询要 2~3 秒 | 全部查询改「一次抓快照 + 本地匹配」 |
| 14 | 底部 tab y 超过 ~1570 落进手势区直接回桌面 | 点击坐标留安全边距 |

## 特性

| 能力 | 说明 |
|---|---|
| 主路径「免N天」 | 发现页 → 右上角入口 → 激励视频 → 天数 +1，VIP 期间也能跑 |
| 双通道定位入口 | OCR 认「免N天」优先，认不出自动退到实测比例坐标 |
| 浮层退出 | 「坚持退出」多档 y 兜底点击，返回键/坐标点全部覆盖 |
| 进度只看真实增长 | 以面板「第N天畅听 已领取」的天数为准，写盘 `progress.json` 跨运行保留；没涨就明确记「尚未 +1 天」 |
| 直播间识别 | 命中直播形式广告直接退出换一条，不参与带货 |
| 会员态识别 | 底部 tab 变「会员」且无金币入口时明确记录，不盲点 |
| 风控待人 | 出现 `bdturing` 短信验证就停下，toast 提示人工输码 |
| OCR 自动降级 | 插件没装也不影响主流程，只打一条告警 |
| 全程落盘日志 | `/sdcard/qishui-autoqishui/run.log`、进度 `/sdcard/qishui-autoqishui/progress.json` |
| 无设备回归 | `node mock/run-mock.js`，六场景全绿 |

## 快速开始

```text
1. 手机装 AutoJs6 6.x（GitHub Releases 下载 APK）
2. AutoJs6 → 左侧菜单 → 无障碍服务 → 打开
3. 把整个 qishui-android-autojs 文件夹拷到 /sdcard/qishui-android-autojs/
4. 打开 main.js，点运行
```

首次运行会弹「是否允许 AutoJs6 录制/投射您的屏幕」，**点「允许」**（录屏只用于 OCR，没装 OCR 插件时其实用不上）。

想要 OCR 认「免N天」，在 AutoJs6「插件中心」装 **Paddle OCR / ML Kit OCR** 任一插件；
不装也能跑，脚本用固定比例坐标点入口，并在日志里标明「走控件+坐标模式」。

详细步骤见 [docs/安装与使用.md](docs/安装与使用.md)。

## 关键参数（config.js）

| 参数 | 默认 | 作用 |
|---|---|---|
| `APP_PACKAGE` | `com.luna.music` | 汽水音乐包名 |
| `AD_ACTIVITY_KEY` | `ExcitingVideoActivity` | 广告页 Activity 关键字 |
| `FREE_ENTRY_PATTERN` | `免\s*\d+\s*天` | OCR 里认「免18天」 |
| `FREE_ENTRY_RATIO` | `[0.893, 0.057]` | 入口坐标兜底（720×1612 实测 643,92） |
| `FREE_AD_WAIT` | `40000` | 点入口后等进广告的最长毫秒 |
| `CONTINUE_DIALOG_RATIO` | `[0.500, 0.624]` | 「坚持退出」坐标（实测 360,1006） |
| `PANEL_CLOSE_RATIO` | `[0.903, 0.623]` | 天数面板 × 坐标（650,1004） |
| `PANEL_CLAIMED_KEYWORD` | `已领取` | 面板里「已领取」标记 |
| `LIVE_KEYWORDS` | `本场点赞/更多直播/…` | 识别直播间形式广告 |
| `AD_TIMEOUT_BASE/MAX` | `28 / 150` | 等广告基础/封顶秒数 |
| `MAX_LOOP_COUNT` | `0` | 最多跑几轮，`0` = 不限 |

界面文案、比例全部集中在 `config.js`，换机型先改 `BASE_WIDTH/BASE_HEIGHT` 与 `FREE_ENTRY_RATIO`。

## 真机实跑记录（2026-11-21）

同一台机、同一次运行，连续多轮：

```
第2轮  已领取天数 22 → 23，本轮 +1 天     （一条广告就够）
第3轮  已领取天数仍是第23天，计入提前解锁进度（尚未 +1 天）
第4轮  已领取天数仍是第23天，计入提前解锁进度（尚未 +1 天）
...
progress.json = {"claimedDay":23}
```

→ 说明「只有真 +1 才判成功」生效，不会把「看完一条但天数没涨」误报成成功；
天数在后台按平台规则累加，凑够条数后下一轮就会涨。

## 必须说明的两件事

**1. 天数不是一条广告涨一天。**
实测第22天一条就 +1，23 天起要连看好几条（浮层会直接写「再看N个视频提前得 第M日免费听」）。
脚本不会硬凑，它只负责该看的广告都看完、并且在真 +1 时给你记上。

**2. 这类自动化可能违反应用的用户协议。**
机械式看广告领时长存在被风控/限制的可能，实测点「去完成」曾弹出短信验证拦截。
本项目仅供学习 AutoJs6 与安卓无障碍自动化的技术实践，请自行评估风险，不要用于商业用途或批量账号操作。
