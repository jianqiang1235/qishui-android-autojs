# 安装与使用（一步一步）

## 一、装 AutoJs6

1. 手机浏览器打开 `https://github.com/SuperMonster003/AutoJs6/releases`
2. 下载最新版本的 `.apk`（通常名字里有 `arm64-v8a` 的那个，你的手机是 64 位就选它）
3. 安装。首次安装会提示"未知来源"，允许即可
4. 打开 AutoJs6，同意用户协议

> 不要用很久没更新的 Auto.js 4.x 旧版，它没有 `ocr` 模块，OCR 兜底会失效（控件层仍能用）。

## 二、开三个权限

| 权限 | 位置 | 说明 |
|---|---|---|
| 无障碍服务 | AutoJs6 首页左侧抽屉 → 无障碍服务 → 打开 | 最核心，没有它一个按钮都点不了 |
| 悬浮窗 | 同上 → 悬浮窗 → 打开 | 用于显示运行状态和停止按钮 |
| 电池优化白名单 | 系统设置 → 电池 → 找到 AutoJs6 → 不受限制 | 否则息屏后脚本会被杀 |

部分手机（小米/华为/OPPO/vivo）还需要：
- 允许 AutoJs6 **后台运行 / 自启动**
- 在**最近任务**里给 AutoJs6 加锁，防止被清理

## 三、把脚本放到手机

三种方式，任选其一：

**A. 数据线拷贝**
1. 手机连电脑，选「传输文件」
2. 把 `qishui-android-autojs` 整个文件夹拷到手机存储的 `Download` 或 `Documents`
3. 打开 AutoJs6 → 左上角「≡」→ 文件/项目 → 找到这个文件夹 → 打开 `main.js`

**B. 用 AutoJs6 自带编辑器**
1. AutoJs6 里点右下角「+」新建项目，命名 `qishui`
2. 把本项目每个文件的内容逐个粘贴进去（目录层级要保持：`lib/` 下的文件要放在对应路径）

**C. 局域网推送**
1. AutoJs6 首页 → 右上角菜单 → 打开「服务」（会显示一个 `http://手机IP:端口` 地址）
2. 电脑浏览器打开这个地址，拖文件上传

## 四、先跑自检

打开 `tools/自检.js` → 运行 → 看控制台输出：

```
[INFO] [通过] 无障碍服务
[INFO] [通过] 截图权限
[INFO] [通过] OCR 模块
[INFO] [通过] 汽水音乐已安装 (com.luna.music)
[INFO] 屏幕尺寸: 1080x2400  SDK=34 ...
[INFO] 关键词组「广告入口」当前界面命中: 否
...
=== 结果: 通过 4 项，失败 0 项 ===
```

- 4 项全过 → 可以跑主流程
- 「汽水音乐已安装」失败 → 包名不对，看 [适配说明.md](适配说明.md)
- 关键词命中「否」→ 正常，因为当时不在播放页/广告页

## 五、跑主流程

1. 打开 `main.js`
2. 点运行
3. 首次会弹「屏幕截图」授权 → **点「立即开始」**
4. 手动把汽水音乐切到前台（或者让脚本自己启动）

跑起来后看 toast 提示：

```
第 1 轮开始
已点开广告入口
倒计时 32s（来源 ui，原文「32秒后可领奖励」）
已点领奖，等待确认
第 1 轮领取成功（累计 1 次）
```

要停止：点 AutoJs6 悬浮窗里的停止按钮，或音量上键（AutoJs6 默认停止方式）。

## 六、看日志

长跑时控制台会被切走，日志文件才是可靠的：

```
/sdcard/qishui-autoqishui/run.log
```

用手机文件管理器打开，或 AutoJs6 内置文件管理器查看。日志长这样：

```
[11-21 15:53:04][STEP] 第 1 轮开始
[11-21 15:53:05][INFO] 倒计时 34s（来源 ui，原文「34秒后可领奖励」）
[11-21 15:53:40][STEP] 第 1 轮领取成功（累计 1 次）
```

结束时会输出统计：

```
=== 运行结束 ===
总轮次: 33  成功: 30  失败: 1  无广告: 2  异常: 0
总耗时: 14分52秒  平均每次成功: 29秒
```

## 七、建议的第一次试跑方式

1. 把 `config.js` 里的 `MAX_LOOP_COUNT` 改成 `3`
2. 跑一遍，看日志确认 3 轮都走通了
3. 再改回 `0`（不限）跑长跑

如果第一次就失败，直接跑 `tools/采集界面.js` 抓当前界面，对照 [适配说明.md](适配说明.md) 改关键词。
