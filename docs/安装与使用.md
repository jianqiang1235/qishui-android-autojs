# 安装与使用（一步一步）

## 一、装 AutoJs6

1. 手机浏览器打开 `https://github.com/SuperMonster003/AutoJs6/releases`
2. 下载最新版本的 `.apk`（通常名字里有 `arm64-v8a` 的那个，你的手机是 64 位就选它）
3. 安装。首次安装会提示"未知来源"，允许即可
4. 打开 AutoJs6，同意用户协议

> 不要用很久没更新的 Auto.js 4.x 旧版，它没有 `ocr` 模块，OCR 兜底会失效（控件层仍能用）。

## 二、开三个权限

| 权限 | 位置 | 说明 |
|---|---|---|
| 无障碍服务 | AutoJs6 首页左侧抽屉 → 无障碍服务 → 打开 | 最核心，没有它一个按钮都点不了 |
| 悬浮窗 | 同上 → 悬浮窗 → 打开 | 用于显示运行状态和停止按钮 |
| 电池优化白名单 | 系统设置 → 电池 → 找到 AutoJs6 → 不受限制 | 否则息屏后脚本会被杀 |

部分手机（小米/华为/OPPO/vivo）还需要：
- 允许 AutoJs6 **后台运行 / 自启动**
- 在**最近任务**里给 AutoJs6 加锁，防止被清理

## 三、把脚本放到手机

三种方式，任选其一：

**A. 数据线拷贝**
1. 手机连电脑，选「传输文件」
2. 把 `qishui-android-autojs` 整个文件夹拷到手机存储的 `Download` 或 `Documents`
3. 打开 AutoJs6 → 左上角「≡」→ 文件/项目 → 找到这个文件夹 → 打开 `main.js`

**B. 用 AutoJs6 自带编辑器**
1. AutoJs6 里点右下角「+」新建项目，命名 `qishui`
2. 把本项目每个文件的内容逐个粘贴进去（目录层级要保持：`lib/` 下的文件要放在对应路径）

**C. 局域网推送**
1. AutoJs6 首页 → 右上角菜单 → 打开「服务」（会显示一个 `http://手机IP:端口` 地址）
2. 电脑浏览器打开这个地址，拖文件上传

## 四、先跑自检

打开 `tools/自检.js` → 运行 → 看控制台输出：

```
[INFO] [通过] 无障碍服务
[INFO] [通过] 截图权限
[INFO] [通过] OCR 模块
[INFO] [通过] 汽水音乐已安装 (com.luna.music)
[INFO] 屏幕尺寸: 1080x2400  SDK=34 ...
[INFO] 关键词组「广告入口」当前界面命中: 否
...
=== 结果: 通过 4 项，失败 0 项 ===
```

- 4 项全过 → 可以跑主流程
- 「汽水音乐已安装」失败 → 包名不对，看 [适配说明.md](适配说明.md)
- 「OCR 模块」失败 → **不影响主流程**，说明 AutoJs6 插件中心里没装 OCR 插件，
  脚本会自动降级为「控件 + 坐标」模式（入口按 643,92 点，进度看面板 desc）
- 关键词命中「否」→ 正常，因为当时不在发现页/广告页

## 五、跑主流程

1. 打开 `main.js`
2. 点运行
3. 首次会弹「是否允许 AutoJs6 录制/投射您的屏幕」→ **点「允许」**
4. 脚本会自己把汽水音乐拉到前台，然后切到「发现」页

脚本的动作就一句话：**点发现页右上角的「免N天」→ 等广告播完 → 领奖 → 点「坚持退出」回 App → 看面板天数有没有涨**。

跑起来后看 toast / 日志：

```
第 1 轮开始
坐标点击「免N天入口(坐标)」 643,92 成功
已进入广告
检测到「领取成功」，广告已完成
广告内弹出「提前解锁」浮层，点坚持退出
已退出广告
已关闭天数面板
已领取天数 22 → 23，本轮 +1 天
第 2 轮领取成功（累计 1 次）
```

看到「已领取天数仍是第N天，本条广告计入提前解锁进度（尚未 +1 天）」是**正常的**：
天数越往后每天要看的条数越多，没凑够就不会涨，脚本不会假报成功。

日志里还会出现两种「看着像报错、其实是正常」的：

- 「这次给的是直播间形式广告 / 直播间广告已领取，继续走领奖流程」
  → 这条给的是直播间广告，**同样算奖励**，脚本等它播完就继续领
- 「连续 6 轮拿不到广告……重启 App 并休息 5 分钟」
  → 今天的 30 天额度用完了（非 VIP 最多免费 30 天），或者广告池暂时没货

启动时如果提示「免费畅听封顶 30 天，今天不用再刷了」，说明已经领满 30 天，明天再跑即可。

要停止：点 AutoJs6 悬浮窗里的停止按钮，或音量上键（AutoJs6 默认停止方式）。

## 六、看日志

长跑时控制台会被切走，日志文件才是可靠的：

```
/sdcard/qishui-autoqishui/run.log
```

用手机文件管理器打开，或 AutoJs6 内置文件管理器查看。日志长这样：

```
[11-21 18:05:12][STEP] 第 2 轮开始（Activity: com.luna.biz.main.main.MainActivity）
[11-21 18:05:16][INFO] 点击「发现」
[11-21 18:05:20][INFO] 当前免费畅听天数: 免23天
[11-21 18:05:22][STEP] 已进入广告
[11-21 18:05:42][INFO] 检测到「领取成功」，广告已完成
[11-21 18:05:50][INFO] 已退出广告
[11-21 18:05:54][INFO] 已领取天数仍是第23天，本条广告计入提前解锁进度（尚未 +1 天）
```

同目录下还有 `progress.json`，记录已经领到第几天：

```json
{"claimedDay":23,"at":1795255512042}
```

结束时会输出统计：

```
=== 运行结束 ===
总轮次: 33  成功: 30  失败: 1  无广告: 2  异常: 0
总耗时: 14分52秒  平均每次成功: 29秒
```

## 七、建议的第一次试跑方式

1. 把 `config.js` 里的 `MAX_LOOP_COUNT` 改成 `3`
2. 跑一遍，看日志确认 3 轮都走通了
3. 再改回 `0`（不限）跑长跑

如果第一次就失败，直接跑 `tools/采集界面.js` 抓当前界面，对照 [适配说明.md](适配说明.md) 改关键词。
