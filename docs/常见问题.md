# 常见问题

## 运行相关

### 点了运行没反应 / 一个按钮都点不了

无障碍服务没开。检查路径：AutoJs6 首页左侧抽屉 → 无障碍服务。
如果显示已开但仍点不了，去系统设置 → 无障碍 → 已下载的应用 → AutoJs6 → 关闭再打开。

三星/小米部分机型还需要额外给 AutoJs6 **"后台弹出界面"** 权限。

### 弹了「屏幕截图 / 录制屏幕」授权框

必须点「允许」。误点「禁止」后 OCR 兜底不可用（控件 + 坐标模式仍能跑），重启脚本会再弹一次。

### 脚本跑着跑着自己停了

八成是被系统杀了。处理顺序：

1. 设置 → 电池 → 应用 → AutoJs6 → 允许后台活动 / 不受限制
2. 最近任务里给 AutoJs6 加锁
3. 小米：设置 → 应用设置 → 应用管理 → AutoJs6 → 省电策略 → 无限制
4. 华为：应用启动管理里把 AutoJs6 改成手动管理，三个开关全开

另外脚本本身会申请屏幕常亮 1 小时，长时间跑建议把 `device.keepScreenOn` 时间调大或改成不设时限。

### 报「无法启动 汽水音乐」

1. 确认装的是汽水音乐本体，不是极速版
2. 跑 `tools/自检.js` 看包名那项
3. 手动打开一次汽水音乐，确保账号已登录、没有卡在开屏广告

### 报「界面要求登录或验证码，脚本暂停」

这是设计行为。汽水音乐偶尔会要求重新登录或弹验证码，这种情况脚本无法处理，需要人工完成后再跑。

## 领奖相关

### 日志里「OCR 引擎不可用」

AutoJs6 6.7+ 把 OCR 拆成插件了。没装插件时脚本会打一条告警并自动降级为「控件 + 坐标」模式。

- 不影响主流程：入口按 643,92 点，进度看面板 desc
- 想恢复 OCR：AutoJs6 → 插件中心 → 装 **Paddle OCR** 或 **ML Kit OCR**

### 日志里「没能回到发现页」

八成是被弹窗盖住了。常见两种：

1. 荣耀系统管家（`com.hihonor.systemmanager`）弹开屏广告 → 手动「强制停止」一次系统管家
2. App 自己的商业弹窗（`AnimatedCommercialSheetDialog`）→ 等几秒或手动点掉，下一轮通常就正常

### 日志里「点了『免N天』没进广告」

三种情况：

1. 这次给的是**直播间形式广告**（日志会有「命中直播间形式广告，退出换一条」）→ 正常，脚本会换一条
2. 进广告了但没有倒计时（广告填充失败/黑屏）→ 平台侧问题，脚本 28 秒后退出重试
3. 点入口时正好有弹窗挡着 → 见上一条

### 卡在广告里退不出来

广告播完会自动弹「再看N个视频提前得 第M日免费听」浮层，**返回键在上面是无效的**，
点右上角 × 也退不出去，点「领取奖励」只会连播下一条。

唯一出路是点浮层里的「坚持退出」（实测 360,1006）。脚本的 `tapContinueExit()` 已经用三档 y 兜底，
如果还是卡住，说明浮层位置变了 → 改 `config.js` 的 `CONTINUE_DIALOG_RATIO` 或 `welfare.js` 的 `CONTINUE_TAP_Y`。

### 日志里「已领取天数仍是第N天，本条广告计入提前解锁进度（尚未 +1 天）」

**这是正常的，不是失败。** 免费畅听的天数越往后每天要看的条数越多：

- 第22天：一条广告 → +1
- 第23天起：浮层直接写「再看3个视频提前得 第24日免费听」，要连看好几条才 +1

脚本不会把「看完一条但天数没涨」误报成成功，凑够条数后下一轮就会打「已领取天数 X → Y，本轮 +1 天」。

### 天数一直不涨

1. 先看 `progress.json` 里的 `claimedDay` 有没有变
2. 确认「坚持退出」那一跳真的回到了 App（日志要有「已退出广告」）
3. 确认面板真的弹了（日志「已关闭天数面板」）—— 面板文字在 desc 里，是唯一可信的进度

### 面板里同时有「第N天 已领取」和「第N+1天 再看X个提前领」

不能取最大天数，否则会把没领的当成领了。`panelClaimed()` 已经改成按坐标距离给「已领取」配对，
如果配错，说明面板排版变了 → 检查 `PANEL_CLAIMED_KEYWORD`。

## 性能与稳定性

### 一晚上只领了几次

可能原因：

| 现象 | 原因 |
|---|---|
| 日志里大量「没有广告可看」 | 当天额度用完，正常 |
| 广告播完但领奖失败 | 关键词没对上，见上节 |
| 每轮都重启 App | 连续无进展触发了重启，说明根因还是没找到按钮 |

### 耗电快 / 手机发烫

脚本本身不耗电，耗电的是**屏幕常亮 + 广告播放**。降低发热：

1. 把屏幕亮度调到最低
2. 关闭自动亮度
3. 手机放通风处，别放床上

### 日志文件太大

`config.js` 里 `LOG_OVERWRITE: true` 表示每次运行覆盖。想保留历史就改成 `false`（追加），
但要记得定期清理 `/sdcard/qishui-autoqishui/` 目录。

## 安全相关

### 会不会被封号

有可能。自动看广告领福利属于机械化操作，平台风控可能识别。
本项目对此**不做任何保证**，也不提供规避风控的方案。建议：

- 用自己主号之外的账号试
- 不要 24 小时挂机，一天跑一两个小时就够了（额度本身也有限）
- 出现异常提示就停几天

### 脚本会读取我的隐私数据吗

不会联网、不上传任何东西。所有代码都在你手机本地，日志也只写在 `/sdcard/qishui-autoqishui/`。
唯一的网络行为是 AutoJs6 自身（它不是脚本发起的）。

## 还是不行

按这个顺序收集信息，通常能自己定位：

1. 跑 `tools/自检.js`，把 4 项结果记下来
2. 跑 `tools/采集界面.js`，拿到 dump 文件
3. 看 `/sdcard/qishui-autoqishui/run.log` 最后 20 行
4. 对照症状表去 `config.js` 改对应关键词
