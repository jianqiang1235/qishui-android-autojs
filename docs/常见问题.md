# 常见问题

## 运行相关

### 点了运行没反应 / 一个按钮都点不了

无障碍服务没开。检查路径：AutoJs6 首页左侧抽屉 → 无障碍服务。
如果显示已开但仍点不了，去系统设置 → 无障碍 → 已下载的应用 → AutoJs6 → 关闭再打开。

三星/小米部分机型还需要额外给 AutoJs6 **"后台弹出界面"** 权限。

### 弹了「屏幕截图」授权框

必须点「立即开始」。如果误点了"取消"，本次运行的 OCR 兜底不可用（控件层仍然能工作），
重启脚本会再弹一次。

### 脚本跑着跑着自己停了

八成是被系统杀了。处理顺序：

1. 设置 → 电池 → 应用 → AutoJs6 → 允许后台活动 / 不受限制
2. 最近任务里给 AutoJs6 加锁
3. 小米：设置 → 应用设置 → 应用管理 → AutoJs6 → 省电策略 → 无限制
4. 华为：应用启动管理里把 AutoJs6 改成手动管理，三个开关全开

另外脚本本身会申请屏幕常亮 1 小时，长时间跑建议把 `device.keepScreenOn` 时间调大或改成不设时限。

### 报「无法启动 汽水音乐」

1. 确认装的是汽水音乐本体，不是极速版
2. 跑 `tools/自检.js` 看包名那项
3. 手动打开一次汽水音乐，确保账号已登录、没有卡在开屏广告

### 报「界面要求登录或验证码，脚本暂停」

这是设计行为。汽水音乐偶尔会要求重新登录或弹验证码，这种情况脚本无法处理，需要人工完成后再跑。

## 领奖相关

### 一直提示「本轮没能进入广告」

`AD_ENTRY_KEYWORDS` 里的文案和实际界面对不上。跑 `tools/采集界面.js`，
把实际按钮文案补进 `config.js`。详见 [适配说明.md](适配说明.md)。

另外确认：**当天的免费听歌额度已经用完了**。额度耗尽时入口按钮会消失或变成会员引导，
这时候无论怎么改关键词都领不到，等第二天恢复。

### 一直提示「等待 40s 仍未出现倒计时」

两种情况：

1. 倒计时文案写法不同 → 改 `COUNTDOWN_PATTERN`
2. 真的没广告在播（比如广告填充失败，黑屏或空白页）→ 这是平台侧问题，脚本只能等下一轮

### 提示「领奖已点击但未看到成功提示」

`CLAIM_OK_KEYWORDS` 没覆盖成功提示的文案。跑采集工具看实际提示（可能是"领取成功"之外的写法），加进去。

也可能是点到了错误的「领取」按钮（界面上有多个含"领取"的控件）。
处理：把 `CLAIM_KEYWORDS` 里太宽泛的 `"领取"` 删掉，只保留完整文案。

### 卡在电商落地页退不出来

脚本有三层兜底：点「完成」→ 返回键/边缘右滑 → 回桌面重启。
如果三层都失败，通常是落地页是自绘 WebView，`back()` 无效。可以：

1. 把 `SWIPE_START_X_RATIO` 调到 `0.001`，让边缘右滑更贴边
2. 在 `lib/app.js` 的 `goBack()` 里加一次 `recents()`（打开最近任务）再 `back()`

日志里会记录每次兜底的层级，按日志调。

## 性能与稳定性

### 一晚上只领了几次

可能原因：

| 现象 | 原因 |
|---|---|
| 日志里大量「没有广告可看」 | 当天额度用完，正常 |
| 广告播完但领奖失败 | 关键词没对上，见上节 |
| 每轮都重启 App | 连续无进展触发了重启，说明根因还是没找到按钮 |

### 耗电快 / 手机发烫

脚本本身不耗电，耗电的是**屏幕常亮 + 广告播放**。降低发热：

1. 把屏幕亮度调到最低
2. 关闭自动亮度
3. 手机放通风处，别放床上

### 日志文件太大

`config.js` 里 `LOG_OVERWRITE: true` 表示每次运行覆盖。想保留历史就改成 `false`（追加），
但要记得定期清理 `/sdcard/qishui-autoqishui/` 目录。

## 安全相关

### 会不会被封号

有可能。自动看广告领福利属于机械化操作，平台风控可能识别。
本项目对此**不做任何保证**，也不提供规避风控的方案。建议：

- 用自己主号之外的账号试
- 不要 24 小时挂机，一天跑一两个小时就够了（额度本身也有限）
- 出现异常提示就停几天

### 脚本会读取我的隐私数据吗

不会联网、不上传任何东西。所有代码都在你手机本地，日志也只写在 `/sdcard/qishui-autoqishui/`。
唯一的网络行为是 AutoJs6 自身（它不是脚本发起的）。

## 还是不行

按这个顺序收集信息，通常能自己定位：

1. 跑 `tools/自检.js`，把 4 项结果记下来
2. 跑 `tools/采集界面.js`，拿到 dump 文件
3. 看 `/sdcard/qishui-autoqishui/run.log` 最后 20 行
4. 对照症状表去 `config.js` 改对应关键词
